===========================
Content Provenance: Signing
===========================

:Extension key:
    provenance_signing

Signs the provenance record and the text of each page with an Ed25519 site key, so anyone can verify that the published content is unchanged (conformance level L3).

This extension is part of the TYPO3 implementation of the
`Content Provenance Specification <https://github.com/dkd-dobberkau/content-provenance-spec>`__.
Installation, configuration, the editorial guide and verification for all
four extensions are documented in one place, the manual of the core extension
`provenance <https://docs.typo3.org/p/cms-provenance/provenance/main/en-us/>`__.
