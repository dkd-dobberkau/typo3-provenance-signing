# Contributing

Thanks for helping build the TYPO3 reference implementation of the Content
Provenance Specification. The project is developed in the open and welcomes
contributors from any agency, company or community.

## Where things go

- **Specification changes** (data model, signatures, endpoints, conformance
  levels) belong in the [specification repository](https://github.com/dkd-dobberkau/content-provenance-spec), not here.
- **Code** for this extension: pull requests against `main` in this repository.
- **Documentation and translations** are welcome here as well and have a lower
  review bar.

## Workflow

1. Open an issue first for anything beyond a small fix, so the approach can be
   discussed.
2. Fork, create a topic branch, keep changes focused.
3. Use [Conventional Commits](https://www.conventionalcommits.org/) for commit
   messages (`feat:`, `fix:`, `docs:` …).
4. Follow the TYPO3 coding guidelines (PER Coding Style, strict types).
5. Add or update tests for behaviour changes.
6. Update `CHANGELOG.md` under *Unreleased*.

Pull requests to this repository need one maintainer approval before merge.
